# Independent fixture authors

The implementation session dispatched two fresh agent contexts without forking
its planning history. Each was assigned only its own publisher directory,
the provisional declaration/result format, and the intended consumer behavior.
The dispatcher explicitly prohibited reading the sibling publisher or shared
implementation. Their resulting design notes are in each `AUTHOR.md`.

Atlas was tasked with materially distinctive task-first CSV summarization
README guidance, an ordinary CSV work skill, an exact configuration replacement,
a repository-level concern, contribution exclusions, and a literal argv probe.
Beacon was tasked with operational/reference-style Markdown link inventory
README guidance, an ordinary link-triage skill, exact full/compact configuration,
a multi-file concern, and exclusion of contribution governance.

The common format described `publisher`, `defaults`, and named complete
`profiles`; whole declarations or `{exclude:true}` overrides; explicit
`kind`/`mode`/target/source/guidance; and fixes/checks with id, literal argv,
executable prerequisites, resolved-selection JSON stdin, and JSON results.
The authors supplied no adoption procedures and no resulting consumer README.

These are independently authored agent fixtures, not evidence from recruited
human publishers. Their independent authorship and the fresh consumer agent
execution answer different questions; only the latter has raw Codex JSONL
transcripts retained in `run/agents/`.
