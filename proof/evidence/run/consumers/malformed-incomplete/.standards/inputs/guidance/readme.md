# Help someone summarize their first file

Open with the user's task: turn a CSV column into a numeric summary. Put a
copyable invocation and its observed output before installation or architecture.
Inspect `app.py` and run it with a tiny CSV to discover its real interface and
result format. Show the input rows alongside that result. Then explain input
requirements and one actual failure case with its observed behavior. Describe
only behavior the current consumer implements. End with a short link to the
repository's contribution instructions when that document exists.
