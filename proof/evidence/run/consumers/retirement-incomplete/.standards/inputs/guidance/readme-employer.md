# Help an internal analyst finish one task

Lead with a runnable CSV summarization example: input rows, actual command, and
observed output. Discover the interface by reading and running `app.py`.
After the example, explain the implemented treatment of invalid input and give
one observed error. Use a short "Working here" paragraph that points to the
existing employer CONTRIBUTING.md for internal review procedures; preserve that
document and its authority. Avoid invented contact people and process details.
