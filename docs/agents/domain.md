# Domain docs

This repository uses a single domain context.

Before exploring or naming repository-standard concepts, read `CONTEXT.md` at
the repository root and the relevant architectural decision records in
`docs/adr/`. If either path does not exist, proceed without creating placeholder
documents; `/domain-modeling` creates them only when language or decisions are
resolved.

Use the glossary's canonical terms in documentation, tests, and code. Surface
any proposed change that contradicts an accepted ADR.
