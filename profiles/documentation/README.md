# Documentation profile

Select this profile for repositories that use the shared Diataxis-oriented
documentation tree. It owns exactly the seven canonical files in
`docs/_templates`.

It does not create empty content sections and does not own `docs/README.md`,
section indexes, decision records, or authored documentation. Those files must
describe the repository's real content.

Codex skill repositories normally keep their operational knowledge in
`skill/references` and should not select this profile.
