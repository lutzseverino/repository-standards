# Agent skills profile

The common profile inherits this profile so every participating repository
receives the standard repository-local agent skills. Each bundle is copied at a
pinned upstream revision and accompanied by a managed inventory and license.

The initial bundle is the official 25-skill `mattpocock-skills` plugin at
`84fdeffd12f2ee307994d1eb6feb48173b6e0502`. Additions and upgrades are
deliberate standards changes; repositories adopt them through a standards
release and synchronization.
